Proposed course syllabus

From Silicon to a Simple CPU

Trace computation from doped silicon and transistor switches to logic, memory, instructions, and a CPU you can design and simulate yourself.

Duration6–8 hours
LevelHardware beginner
Starting pointSoftware engineer
DestinationWorking tiny CPU
01

What you’ll be able to do

01

Explain how silicon, doping, and MOSFETs produce controllable digital switches.

02

Build combinational and sequential circuits from gates, with timing in mind.

03

Read a CPU datapath and follow one instruction through the fetch–execute cycle.

04

Define, assemble, and simulate programs for a small CPU of your own design.

02

The learning path

M01

The physical substrate 45 min

From sand to patterned silicon

Concepts

  • Conductors, insulators, and semiconductors
  • Silicon crystal, electrons, holes, and doping
  • Wafers, lithography, deposition, etching, and yield
Interactive checkpoint Walk through a simplified fabrication flow and predict how each layer contributes to a transistor.
M02

Transistors become logic 50 min

Voltage, switching, CMOS, and abstraction

Concepts

  • NMOS and PMOS as voltage-controlled switches
  • CMOS inverter, NAND, and NOR circuits
  • Noise margins, propagation delay, and power
Interactive checkpoint Toggle transistor gates and derive the truth tables of CMOS circuits from current paths.
M03

Computing with gates 55 min

Bits, Boolean logic, arithmetic, and selection

Concepts

  • Binary, hexadecimal, and two’s complement
  • Half/full adders and multi-bit ripple addition
  • Multiplexers, decoders, and a small ALU
Build checkpoint Assemble a 4-bit ALU that can add, subtract, AND, and select values.
M04

Remembering state 55 min

Feedback, clocks, registers, and memory

Concepts

  • Latches, flip-flops, and clocked state
  • Registers, counters, SRAM, and DRAM
  • Setup/hold time and the synchronous model
Interactive checkpoint Step a clock by hand and track how state moves through a register and program counter.
M05

A programmer’s CPU map 50 min

ISA, datapath, control, and the instruction cycle

Concepts

  • Architecture versus microarchitecture
  • Registers, ALU, buses, memory, and control unit
  • Fetch, decode, execute, and store
Trace checkpoint Follow encoded instructions through the datapath and connect them to familiar software operations.
M06

Design the tiny architecture 60 min

Make the decisions that define a CPU

Concepts

  • Word width, instruction encoding, and addressing
  • Accumulator datapath and control signals
  • Branches, flags, and memory-mapped I/O
Design checkpoint Specify the instruction set and complete a control table before wiring the machine.
M07

Build, program, and debug it 90–120 min

Integrate the datapath and bring the CPU to life

Concepts

  • Wire the datapath and implement hardwired control
  • Hand-assemble and load a small program
  • Single-step, inspect state, and diagnose faults
Capstone Run a loop that adds a sequence of values and writes the result to an output register.
Final build

An 8-bit accumulator CPU

A deliberately small machine: complex enough to be a real stored-program computer, small enough to hold in your head.

Data width8 bits
Memory16 × 8
Core stateACC · PC · IR · flags
Instructions8–10
ControlHardwired FSM
MediumBrowser simulator

The design favors visible state and clear causality over speed or realism.

Assumed, not required

  • Comfort reading code and following state changes
  • Basic arithmetic and high-school algebra
  • No electronics, physics, or HDL experience

Intentionally out of scope

  • Analog circuit design and transistor equations
  • Pipelining, caches, superscalar execution, and virtual memory
  • Professional chip layout, verification, and fabrication tooling
